Co je pole v PHP

Pole v PHP je uspořádaná mapa: každá hodnota má klíč a pole si pamatuje pořadí vložení. Klíčem je celé číslo (indexované pole) nebo řetězec (asociativní pole). Obojí lze v jednom poli kombinovat.

Indexované pole (seznam)

$ovoce = ['jablko', 'hruška', 'švestka'];   // klíče 0, 1, 2
echo $ovoce[0], "\n";
echo count($ovoce), " položky\n";

$ovoce[] = 'meruňka';        // přidání na konec → klíč 3
print_r($ovoce);

$stary = array(1, 2, 3);     // starší zápis, funguje dál

Přístup a úpravy

Vícerozměrná pole

Hodnotou prvku může být další pole. Nejčastější podoba dat v praxi je seznam záznamů: indexované pole asociativních polí. Stejně vypadá výsledek dotazu do databáze i načtený JSON.

Matice

$m = [
    [1, 2, 3],
    [4, 5, 6],

echo $m[1][2], "\n";             // řádek 1, sloupec 2

foreach ($m as $radek) {
    echo implode("\t", $radek), "\n";
}

// transpozice
$t = array_map(null, ...$m);
foreach ($t as $radek) { echo implode(' ', $radek), "\n"; }

Destrukturace, spread a slučování

Destrukturace přiřadí prvky pole do proměnných jedním příkazem. Spread ... naopak pole rozbalí. Pro slučování polí existují dva způsoby s rozdílným chováním.

Destrukturace seznamu

$bod = [3, 7];
[$x, $y] = $bod;
echo "x=$x y=$y\n";

[$x, $y] = [$y, $x];               // prohození
echo "x=$x y=$y\n";

[, $druhy, , $ctvrty] = [1, 2, 3, 4];   // přeskočení
echo "$druhy $ctvrty\n";

[$a, [$b, $c]] = [1, [2, 3]];     // vnořené
echo "$a $b $c\n";

[$den, $mesic, $rok] = explode('.', '16.10.2026');
echo "$rok-$mesic-$den\n";

Hledání a testy

Hledání v poli má dvě pasti: volné porovnání (bez třetího parametru true) a výsledek 0, který podmínka bere jako nepravdu. Obě řeší striktní porovnání.

// zásobník (LIFO): kontrola závorek
function zavorkyOk(string $s): bool
{
    $par = [')' => '(', ']' => '[', '}' => '{'];
    $zasobnik = [];
    foreach (str_split($s) as $z) {
        if (in_array($z, $par, true)) {
            $zasobnik[] = $z;
        } elseif (isset($par[$z]) && array_pop($zasobnik) !== $par[$z]) {
            return false;
        }
    }
    return $zasobnik === [];
}
