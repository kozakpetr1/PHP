Struktura skriptu

PHP soubor je obyčejný textový soubor s příponou .php. Interpret vykonává jen kód mezi značkami <?php a ?>. Všechno mimo ně pošle beze změny na výstup.

Čistý PHP soubor

<?php
declare(strict_types=1);   // volitelně: přísná kontrola typů

$jmeno = 'Petr';
echo "Ahoj, $jmeno!\n";
echo 'Dnes je ', date('l'), ".\n";
Ahoj, Petr!
Dnes je Friday.
  • Každý příkaz končí středníkem ;.
  • Soubor, který obsahuje jen PHP, nemá uzavírací ?>. Zabráníte tím nechtěnému odeslání mezer či odřádkování za ním.
  • declare(strict_types=1); musí být úplně první příkaz souboru (víc v prezentaci 3).

PHP uvnitř HTML (šablona)

<?php $nadpis = 'Rozvrh'; $hodin = 6; ?>
<h1><?= $nadpis ?></h1>
<p>Dnes máte <?= $hodin ?> hodin.</p>
<?php if ($hodin > 5): ?>
  <p>Bude to dlouhý den.</p>
<?php endif; ?>
<h1>Rozvrh</h1>
<p>Dnes máte 6 hodin.</p>
  <p>Bude to dlouhý den.</p>

<?= výraz ?> je zkratka za <?php echo výraz; ?>. Za posledním příkazem před ?> středník být nemusí.

Krátkou značku <? (bez php) nepoužívejte. Funguje jen se zapnutým short_open_tag. <?= funguje vždy.

Proměnné

Proměnná začíná znakem $. Nedeklaruje se, vznikne prvním přiřazením. Typ se určuje podle hodnoty a může se během běhu změnit.

Vytvoření a přiřazení

$vek = 17;               // int
$jmeno = 'Adam';         // string
$prumer = 1.85;          // float
$plnolety = $vek >= 18;  // bool

var_dump($vek, $plnolety);

$vek = 'sedmnáct';       // stejná proměnná, jiný typ
var_dump($vek);
int(17)
bool(false)
string(9) "sedmnáct"

Pravidla pro názvy

  • začíná písmenem nebo _, pak písmena, číslice, _
  • $pocetZaku ✓   $_tmp ✓   $2trida ✗   $pocet-zaku ✗
  • konvence: camelCase, anglicky nebo česky bez diakritiky, ale jednotně
  • $this je vyhrazené

Kopie × odkaz (reference)

$a = 10;
$b = $a;      // kopie hodnoty
$b++;
echo "a=$a, b=$b\n";

$c = &$a;     // $c je jiné jméno pro $a
$c++;
echo "a=$a, c=$c\n";

unset($c);    // zruší jen jméno $c, $a zůstává
echo "a=$a\n";

a=11, c=11
a=11
Reference používejte střídmě. Typicky jen u foreach (... as &$v) nebo u parametru funkce, který má funkce změnit.

Podmínky

Podmínka vyhodnotí výraz jako true, nebo false a podle toho vybere větev. Hodnoty jiného typu převede na bool (pravidla v prezentaci 3).

if / elseif / else

$body = 74;

if ($body >= 90) {
    $znamka = 1;
} elseif ($body >= 75) {
    $znamka = 2;
} elseif ($body >= 50) {
    $znamka = 3;
} else {
    $znamka = 5;
}
echo "Známka: $znamka\n";
Známka: 3

Pište elseif dohromady. else if funguje také, ale v alternativní syntaxi ne.

if (!in_array($role, ['admin', 'ucitel'], true)) {

Výraz match

match je výraz, ne příkaz. Vrací hodnotu, kterou lze rovnou přiřadit. Porovnává přes === a když žádná větev nesedí, vyhodí chybu, místo aby tiše pokračoval.

Základní použití

$kod = 404;

$zprava = match ($kod) {
    200, 204 => 'OK',
    301, 302 => 'Přesměrování',
    404      => 'Nenalezeno',
    500      => 'Chyba serveru',
    default  => 'Neznámý stav',
};
echo $zprava, "\n";
Nenalezeno
  • více hodnot v jedné větvi oddělte čárkou
  • každá větev je jeden výraz (ne blok příkazů)
  • za poslední větví smí být čárka

Cyklus opakuje blok příkazů. for se hodí pro známý počet opakování, while pro neznámý a foreach pro procházení pole.

Proč __DIR__

Relativní cesta 'config.php' se hledá podle include_path a aktuálního pracovního adresáře. Ten závisí na tom, odkud byl skript spuštěn (jiný v CLI, jiný na webu). __DIR__ je vždy složka souboru, ve kterém je zapsán.

Nikdy nevkládejte soubor podle vstupu od uživatele (include $_GET['stranka']). Je to klasická díra typu file inclusion.
