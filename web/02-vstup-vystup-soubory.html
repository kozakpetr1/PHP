Formátovaný výstup

Výstup skriptu jde v terminálu na obrazovku a na webu do těla HTTP odpovědi. Pro hezké tabulky, čísla a ceny slouží rodina funkcí printf.

printf a sprintf

$jmeno = 'Eva'; $body = 42; $procent = 87.456;

printf("%s má %d bodů (%.1f %%)\n", $jmeno, $body, $procent);

$radek = sprintf('%05d|%-8s|%8.2f|', 42, 'PHP', 3.14159);  // vrátí řetězec
echo $radek, "\n";

printf("%1\$s, %2\$s a zase %1\$s\n", 'A', 'B');        // pořadí argumentů
printf("[%'*10s]\n", 'hvězdy');                          // vlastní výplň
Eva má 42 bodů (87.5 %)
00042|PHP     |    3.14|
A, B a zase A
[***hvězdy]

printf vypisuje, sprintf vrací text, fprintf zapisuje do souboru.

Výstup do prohlížeče

Na webu PHP posílá dvě věci: HTTP hlavičky a tělo odpovědi. Hlavičky musí odejít dřív než první znak těla. Text od uživatele se do HTML musí vždy escapovat.

htmlspecialchars: ochrana proti XSS

$komentar = '<script>alert("hack")</script> & <b>tučně</b>';

echo "<p>$komentar</p>\n";                         // ✗ nebezpečné
echo '<p>', htmlspecialchars($komentar), "</p>\n"; // ✓ bezpečné

function e(?string $s): string            // zkratka do šablon
{
    return htmlspecialchars($s ?? '', ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
echo '<input value="', e('Řekl "ahoj"'), "\">\n";
<p><script>alert("hack")</script> & <b>tučně</b></p>
<p>&lt;script&gt;alert(&quot;hack&quot;)&lt;/script&gt; &amp; &lt;b&gt;tučně&lt;/b&gt;</p>
<input value="Řekl &quot;ahoj&quot;">
XSS (Cross-Site Scripting): útočník vloží do formuláře JavaScript a ten se spustí každému, kdo stránku otevře. Escapujte při výpisu, ne při ukládání.

Text s odřádkováním

$zprava = "Dobrý den,\nposílám úkol.\n<b>Petr</b>";
echo nl2br(htmlspecialchars($zprava));
Dobrý den,<br />
posílám úkol.<br />
&lt;b&gt;Petr&lt;/b&gt;

Nejdřív escapovat, potom nl2br. Jinak by se escapovaly i vložené značky <br>.

Odkazy a URL

$hledat = 'čeština & PHP';
echo '<a href="hledat.php?q=', urlencode($hledat), '">hledat</a>', "\n";
echo http_build_query(['q' => $hledat, 'strana' => 2]);

Vstup v příkazové řádce

Skript spuštěný v terminálu (php skript.php) dostává vstup třemi cestami: argumenty na příkazové řádce, standardní vstup (klávesnice nebo přesměrovaný soubor) a proměnné prostředí.

Čtení z klávesnice

echo 'Jak se jmenuješ? ';
$jmeno = trim(fgets(STDIN));          // přečte jeden řádek včetně \n

echo 'Kolik ti je? ';
$vek = (int) fgets(STDIN);

echo "\nAhoj $jmeno, za rok ti bude ", $vek + 1, ".\n";
Jak se jmenuješ? Kolik ti je? 
Ahoj Eva, za rok ti bude 18.

Ve výstupu chybí zadaný text, protože ten se zobrazí jen na klávesnici. fgets vrací řádek i se znakem \n, proto trim().

readline a fscanf

$a = readline('Zadej číslo: ');       // výzva + řádek bez \n
echo "Zadal jsi $a\n";
// fscanf: rozdělí vstup podle formátu
[$x, $y] = fscanf(STDIN, '%d %d') ?? [0, 0];
echo "Součin: ", $x * $y, "\n";

Vstup z webu: GET a POST

Na webu přicházejí data v HTTP požadavku. PHP je před spuštěním skriptu rozparsuje do superglobálních polí, která jsou dostupná všude, i uvnitř funkcí.

Superglobální pole

PoleObsahuje
$_GETparametry z URL: ?q=php&strana=2
$_POSTdata formuláře s method="post"
$_FILESnahrané soubory
$_COOKIEcookies z prohlížeče
$_SESSIONdata relace (po session_start())
$_SERVERinformace o požadavku a serveru
$_ENVproměnné prostředí
$_REQUESTGET + POST + COOKIE dohromady (nepoužívat)
Všechno v těchto polích jsou řetězce (nebo pole řetězců) a posílá je uživatel, takže mohou obsahovat cokoli.

GET: parametry v adrese

<?php // hledat.php?q=php&strana=2
$q = trim($_GET['q'] ?? '');
$strana = max(1, (int) ($_GET['strana'] ?? 1));
?>
<form method="get">
  <input name="q" value="<?= htmlspecialchars($q) ?>">
  <button>Hledat</button>
</form>
<?php if ($q !== ''): ?>
  <p>Hledáte „<?= htmlspecialchars($q) ?>“, strana <?= $strana ?>.</p>
<?php endif; ?>

GET pro čtení (hledání, filtry, stránkování): adresa jde uložit do záložek a sdílet.

POST: zpracování formuláře

<?php // kontakt.php
$chyby = [];
$data = ['jmeno' => '', 'email' => '', 'zprava' => ''];

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $data['jmeno']  = trim($_POST['jmeno'] ?? '');
    $data['email']  = trim($_POST['email'] ?? '');
    $data['zprava'] = trim($_POST['zprava'] ?? '');

    if ($data['jmeno'] === '')                                $chyby[] = 'Vyplňte jméno.';
    if (!filter_var($data['email'], FILTER_VALIDATE_EMAIL))   $chyby[] = 'Neplatný e-mail.';
    if (mb_strlen($data['zprava']) < 10)                      $chyby[] = 'Zpráva je krátká.';

    if ($chyby === []) {
        file_put_contents(__DIR__ . '/zpravy.log', json_encode($data) . "\n", FILE_APPEND | LOCK_EX);
        header('Location: kontakt.php?odeslano=1', true, 303);
        exit;
    }
}
?>
<?php foreach ($chyby as $ch): ?><p class="chyba"><?= htmlspecialchars($ch) ?></p><?php endforeach; ?>
<form method="post">
  <input name="jmeno" value="<?= htmlspecialchars($data['jmeno']) ?>">
  <input name="email" type="email" value="<?= htmlspecialchars($data['email']) ?>">
  <textarea name="zprava"><?= htmlspecialchars($data['zprava']) ?></textarea>
  <button>Odeslat</button>
</form>

Co se děje

  1. První načtení stránky je GET: zobrazí se prázdný formulář.
  2. Odeslání je POST: data přijdou v $_POST, klíčem je atribut name.
  3. Při chybě se formulář vykreslí znovu s vyplněnými hodnotami a hláškami.
  4. Při úspěchu přesměrování 303. Obnovení stránky (F5) pak formulář neodešle podruhé.

Validace vstupu a nahrávání souborů

Vstupu nikdy nevěřte. Každou hodnotu ověřte (je to číslo? e-mail? v povoleném rozsahu?) a teprve pak s ní pracujte. Funkce filter_var ověří i převede typ v jednom kroku.

filter_var

var_dump(filter_var('42', FILTER_VALIDATE_INT));
var_dump(filter_var('42abc', FILTER_VALIDATE_INT));       // false
var_dump(filter_var('15', FILTER_VALIDATE_INT,
    ['options' => ['min_range' => 1, 'max_range' => 5]]));   // false
var_dump(filter_var('3,14', FILTER_VALIDATE_FLOAT,
    ['options' => ['decimal' => ',']]));
var_dump(filter_var('eva@skola.cz', FILTER_VALIDATE_EMAIL));
var_dump(filter_var('ano', FILTER_VALIDATE_BOOL, FILTER_NULL_ON_FAILURE));
var_dump(filter_var('yes', FILTER_VALIDATE_BOOL, FILTER_NULL_ON_FAILURE));

Vlastní validace

function overPsc(string $psc): ?string
{
    $psc = str_replace(' ', '', $psc);
    return preg_match('/^\d{5}$/', $psc) ? $psc : null;
}

foreach (['407 47', '40747', '4O747', '1234'] as $v) {
    printf("%-7s → %s\n", $v, overPsc($v) ?? 'neplatné');
}

40747   → 40747
4O747   → neplatné
1234    → neplatné

function smazStrom(string $slozka): void
{
    $it = new RecursiveIteratorIterator(
        new RecursiveDirectoryIterator($slozka, FilesystemIterator::SKIP_DOTS),
        RecursiveIteratorIterator::CHILD_FIRST      // nejdřív obsah, pak složka
    );
    foreach ($it as $info) {
        $info->isDir() ? rmdir($info->getPathname()) : unlink($info->getPathname());
    }
    rmdir($slozka);
}

CLI skript dostane jako argument cestu k přístupovému logu Apache, čte ho po řádcích a vypíše 5 nejčastějších IP adres a počet odpovědí 404. Chybu hlásí na STDERR s kódem 1.

Úloha 3: Záloha složky

Skript projde zadanou složku rekurzivně, zkopíruje do zaloha/RRRR-MM-DD/ soubory změněné za posledních 7 dní (zachová podsložky) a vypíše jejich počet a celkovou velikost.
