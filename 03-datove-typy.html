Typový systém PHP

PHP je dynamicky typovaný jazyk: typ nemá proměnná, ale hodnota v ní. Stejná proměnná může nejdřív obsahovat číslo a potom text. Typy parametrů a vlastností ale lze (a je vhodné) deklarovat.

Logický typ bool

Typ bool má jen dvě hodnoty: true a false. Na bool se převede každá hodnota v podmínce. Je proto důležité vědět, které hodnoty se chovají jako nepravda (falsy).

Hodnoty, které jsou false

$falsy = [false, 0, 0.0, -0.0, '', '0', [], null];
foreach ($falsy as $v) {
    echo str_pad(json_encode($v), 6), ' → ', $v ? 'true' : 'false', "\n";
}
false  → false
0      → false
0      → false
-0     → false
""     → false
"0"    → false
[]     → false
null   → false

Všechno ostatní je true, včetně objektů a záporných čísel.

Pasti: tohle je true

$pasti = ['0.0', ' ', 'false', '00', [0], -1, 0.1, 'null'];
foreach ($pasti as $v) {
    echo str_pad(json_encode($v), 8), ' → ', var_export((bool) $v, true), "\n";
}
"0.0"    → true
" "      → true
"false"  → true
"00"     → true
[0]      → true

0.1      → true
"null"   → true
Řetězec 'false' je true, protože není prázdný. Vstup z formuláře proto převádějte přes filter_var($v, FILTER_VALIDATE_BOOL).

Kde na tom záleží

$pozice = strpos('PHP je super', 'PHP');   // 0 = nalezeno na začátku

if ($pozice) {
    echo "nalezeno (if)\n";                 // neproběhne!
}
if ($pozice !== false) {
    echo "nalezeno (!== false)\n";          // správně
}
var_dump(str_contains('PHP je super', 'PHP'));  // od 8.0 jednodušeji

Funkce, které vrací číslo nebo false (strpos, array_search), testujte vždy přes === false.

Výpis bool

$ok = true; $chyba = false;
echo "ok: [$ok], chyba: [$chyba]\n";     // true → "1", false → ""
echo 'ok: ', var_export($ok, true), "\n";

Při převodu na řetězec je true „1“ a false prázdný řetězec. Pro výpis použijte ternární operátor nebo var_export.

Celá čísla int

Typ int je celé číslo se znaménkem. Na 64bitových systémech má rozsah zhruba ±9,2 × 1018. Při překročení rozsahu se z výsledku tiše stane float.

$velke = 1_000_000;   // oddělovač tisíců (7.4)

var_dump($dec === $hex, $hex === $oct, $oct === $bin);
echo $velke, "\n";
echo dechex(255), ' ', decbin(10), ' ', decoct(8), ' ', bindec('1010'), "\n";

Desetinná čísla float

float je číslo s plovoucí řádovou čárkou podle IEEE 754 (dvojitá přesnost). Většinu desetinných zlomků neumí uložit přesně, protože počítá ve dvojkové soustavě.

Zápis a nepřesnost

$a = 1.5;

var_dump(0.1 + 0.2);
var_dump(0.1 + 0.2 == 0.3);
echo 0.1 + 0.2, "\n";             // echo zaokrouhlí, var_dump ne
printf("%.20f\n", 0.1);

Řetězce jako typ

Hodnota null

null znamená „bez hodnoty“. Má ji proměnná, které se null přiřadí, funkce bez return nebo neexistující prvek přečtený přes ??.

$b = @$neexistuje;              // nedefinovaná (s potlačeným varováním)
$c = ['x' => 1]['y'] ?? null;
$d = (function () {})();        // funkce bez return

var_dump($a, $b, $c, $d);
var_dump(null === NULL);        // klíčové slovo bez ohledu na velikost

Kapitola 8 / 12 · Přetypování

Explicitní přetypování

Přetypování zapíšete typem v závorce před hodnotou: (int) $x. Na rozdíl od automatiky nikdy nehlásí chybu. Vždy vrátí nějaký výsledek, i když nemusí dávat smysl.

Čísla a text tam a zpět

Nejčastější převod v praxi: uživatel napíše „1 234,50“ a program potřebuje float. Opačně se float musí vypsat v české podobě. Obojí jde spolehlivě, když se ví, kterou funkci použít.

Text → číslo spolehlivě

function naCislo(string $vstup): ?float
{
    $s = str_replace([' ', "\u{A0}", ','], ['', '', '.'], trim($vstup));
    $f = filter_var($s, FILTER_VALIDATE_FLOAT);
    return $f === false ? null : $f;
}

foreach (['1 234,50', '12.5', '-3', '1e3', '12a', ''] as $v) {

}

Shrnutí a úlohy

Typové chyby patří k nejčastějším chybám v PHP. Většině z nich předejdete několika pravidly.

Pravidla

  1. declare(strict_types=1); na začátku každého souboru.
  2. Typy u všech parametrů, návratových hodnot a vlastností.
  3. Porovnávejte přes === a !==.
  4. Vstup zvenku nejdřív ověřte (filter_var) a teprve pak používejte.
  5. Peníze v celých haléřích nebo přes bcmath, nikdy ve float.
  6. Funkce vracející int|false testujte === false.
  7. Na text v UTF-8 funkce mb_*.

Rychlý test

Úloha 1: Převodník

CLI skript načte z klávesnice libovolný text a vypíše, jak by dopadl převod na int, float, bool, zda je číselný (is_numeric) a co vrátí filter_var s FILTER_VALIDATE_INT a FLOAT.

Úloha 2: Účtenka

Pole položek ['název', cena v Kč jako string s čárkou, počet]. Převeďte ceny na haléře, spočítejte mezisoučty, DPH 21 % a celkovou cenu. Vypište česky formátovanou účtenku.

Úloha 3: Typová kontrola

Funkce ulozZaka(string $jmeno, int $rocnik, ?string $email = null): array se strict_types. Zavolejte ji s daty z formuláře (řetězce) tak, aby nevznikl TypeError, a neplatné hodnoty ohlaste uživateli.
