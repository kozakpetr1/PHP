Výrazy a příkazy

Výraz je cokoli, co má hodnotu: 5, $x, $x + 1, strlen($s), i přiřazení $a = 3. Příkaz je instrukce zakončená středníkem. Operátor z jednoho nebo více operandů vytvoří novou hodnotu.

Části výrazu

$cena * 1.21 + $doprava

operandy jsou hodnoty, operátory říkají, co s nimi udělat.

AritaPočet operandůPříklad
unární1-$x, !$ok, $i++
binární2$a + $b, $a && $b
ternární3$a ? $b : $c

Všechno je výraz

$a = 5;                   // přiřazení je výraz s hodnotou 5
$b = ($c = 3) + 1;        // proto jde použít uvnitř jiného výrazu
echo "$a $b $c\n";

$x = $y = $z = 0;         // řetězené přiřazení (zprava doleva)

echo strlen('PHP') * 2, "\n";    // volání funkce je výraz
echo $a > 3 ? 'velké' : 'malé', "\n";
var_dump($a > 3);                // porovnání je výraz typu bool

Unární operátory

Unární operátor pracuje s jediným operandem. Nejčastější jsou ++ a --. Záleží na tom, zda stojí před proměnnou (nejdřív změna, pak hodnota), nebo za ní (nejdřív hodnota, pak změna).

Prefix × postfix

$i = 5;
echo $i++, "\n";   // vypíše 5, pak zvýší na 6
echo $i, "\n";     // 6
echo ++$i, "\n";   // zvýší na 7, pak vypíše 7
echo $i--, ' ', $i, "\n";
echo --$i, "\n";

Bitové operátory

Bitové operátory pracují s celými čísly bit po bitu. V PHP je potkáte hlavně u příznaků (JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE), u error_reporting a u práv souborů.

Přehled

$a = 0b1100;   // 12
$b = 0b1010;   // 10
printf("a      %04b\n", $a);
printf("b      %04b\n", $b);
printf("a & b  %04b  (AND)\n", $a & $b);
printf("a | b  %04b  (OR)\n", $a | $b);
printf("a ^ b  %04b  (XOR)\n", $a ^ $b);
printf("a << 1 %05b (posun vlevo = ×2)\n", $a << 1);
printf("a >> 2 %04b  (posun vpravo = ÷4)\n", $a >> 2);
echo '~a = ', ~$a, "\n";

const CIST   = 0b001;   // 1

Řetězcové a ostatní operátory

Kromě matematiky a logiky má PHP operátory pro řetězce, pro práci s null, pro objekty a pole. Některé jsou novinkou posledních verzí.

Pipe operátor 8.5+

    |> (fn($s) => str_replace(' ', '-', $s));

Kapitola 10 / 10 · Priority

Pasti a úlohy

Většina chyb s operátory vzniká ze spoléhání na prioritu nebo na automatický převod typů. Závorky a striktní porovnání nic nestojí a ušetří spoustu hledání.

Deset pastí

var_dump('abc' == 0);               // 1: PHP 8 false, PHP 7 true
var_dump(0.1 + 0.2 == 0.3);         // 2: nepřesnost floatu
var_dump(strpos('abc', 'a') == false);  // 3: pozice 0 je falsy
var_dump(-3 ** 2);                  // 4: -(3**2)
$r = true and false; var_dump($r);  // 5: and pod přiřazením
var_dump(7 / 2);                    // 6: dělení vrací float
var_dump(-7 % 3);                   // 7: znaménko zbytku
var_dump('10' < '9a');              // 8: porovnání jako text
var_dump(null == false, [] == false);   // 9: volné porovnání
$i = 1; var_dump($i++ + $i);        // 10: vedlejší efekt ve výrazu

Zásady čitelných výrazů

  1. Když si nejste jistí prioritou, napište závorky. Čtenář to neví také.
  2. === a !== jako výchozí volba.
  3. && a ||, nikdy and a or.
  4. Žádné vnořené ternární operátory, raději match.
  5. ++ a přiřazení jako samostatný příkaz, ne uvnitř jiného výrazu.
  6. Dlouhou podmínku rozdělte do pojmenovaných proměnných.
// ✗
if ($u && $u['vek'] >= 18 && !$u['blok'] || $u['role'] === 'admin') {}

// ✓
$jeDospely = $u !== null && $u['vek'] >= 18 && !$u['blok'];
$jeAdmin = ($u['role'] ?? null) === 'admin';
if ($jeDospely || $jeAdmin) {}
